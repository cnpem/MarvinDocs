# Princípios FAIR

Os princípios [FAIR](https://www.go-fair.org/fair-principles/) são diretrizes para tornar os dados de pesquisa mais acessíveis, interoperáveis e reutilizáveis. FAIR é um acrônimo que significa:

- **<ins>F</ins>indable:** Os dados devem ser fáceis de encontrar por humanos e máquinas.
- **<ins>A</ins>ccessible:** Os dados devem ser acessíveis de forma clara e transparente, com informações sobre como obtê-los.
- **<ins>I</ins>nteroperable:** Os dados devem ser compatíveis com outros conjuntos de dados e sistemas, permitindo a integração e o uso conjunto.
- **<ins>R</ins>eusable:** Os dados devem ser descritos de forma que possam ser reutilizados em diferentes contextos e por diferentes usuários.
