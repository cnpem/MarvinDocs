# AJUDA

Criamos dois agentes de IA para ajudar os usuários a interagir com o sistema de computação de alto desempenho (HPC) descrito neste manual.
Um é o Marvin (Gemini), que utiliza o modelo Gemini do Google e é acessível a todos os usuários, e o outro é o Marvin (Copilot), que utiliza o modelo Copilot do Microsoft e é acessível apenas a usuários do CNPEM.
