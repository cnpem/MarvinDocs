# Gerenciamento de dados

Os dados são gerenciados a nível de usuário no HPCC Marvin.

Essa seção apresenta informações sobre gerenciamento de dados, com informações detalhadas sobre:

- [Armazenamento de dados](armazenamento-de-dados.md)
- [Transferência de dados](transferencia-de-dados.md)
- [Compartilhamento de dados](compartilhamento-de-dados.md)
- [Princípios FAIR](principios-fair.md)

<div class="warning">
⚠️ <b>Ainda não há sistema de backup no HPCC Marvin.</b>

Todos os dados armazenados pelos usuários (dados, scripts, resultados, arquivos temporários, etc) são de responsabilidade do usuário.

Recomenda-se fortemente o uso do sistema de controle de versão <a href="https://git-scm.com/" target="_blank">Git</a> sempre que possível, a fim de manter um histórico de alterações e facilitar a recuperação de informações.
</div>
